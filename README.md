# Нәзік сәт wedding invitation recreation

Private static recreation requested from screenshots and https://shaqyru.kz/site-templates/uilenu_toi/1.

## Included
- Original olive/beige design, invitation sections, fonts and decorative assets
- Animated envelope opening, hummingbirds, sparkles, branch reveals and pulsing calendar heart
- Music toggle, calendar, location link and countdown
- Keyboard-accessible RSVP and wishes dialogs with local browser persistence

## Demo boundaries
The reference example names, hosts, date (5 April 2026), venue and photo are retained. The date is in the past, so the countdown correctly displays zero. RSVP responses and wishes are saved only in the current browser; there is no server collection or submission to the original service. Labels disclose this on the page. No analytics or original third-party submission endpoints are included. Configure genuine event details and server-side collection before using for a real event. Visual assets and music originate from the supplied reference and have not been represented as newly owned or licensed for unrelated redistribution.

## Files
`dist/index.html` contains the editable invitation content. `dist/assets/style.css` and `dist/app.css` provide styling; `dist/assets/animation.js` and `dist/app.js` provide motion and interactions. All assets are local. No build dependencies.
